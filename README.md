# Claude Code 시작하기

> AI 페어 프로그래머와 함께하는 개발의 미래

Claude Code가 스스로 작성한 Claude Code 입문서입니다.

## 📖 웹으로 읽기

**[👉 GitHub Pages로 바로 읽기](https://coalab.github.io/book-claude-code/)**

페이지 넘기기 애니메이션이 있는 인터랙티브 웹 뷰어입니다.
키보드 `←` `→` 또는 터치 스와이프로 페이지를 넘깁니다.

## 📚 목차

| 파트 | 챕터 | 내용 |
|------|------|------|
| **파트 1: 시작하기** | 1-3장 | 설치, 환경 설정, 첫 세션 |
| **파트 2: 핵심 기능** | 4-7장 | Read/Edit/Bash/Grep/Glob 마스터 |
| **파트 3: 고급 워크플로우** | 8-11장 | CLAUDE.md, 멀티 에이전트, 훅, MCP |
| **파트 4: 실전 프로젝트** | 12-15장 | 풀스택 개발, 레거시 현대화, 디버깅, 팀협업 |
| **파트 5: 최적화와 미래** | 16-18장 | 프롬프트 엔지니어링, 비용, 미래 전망 |
| **부록** | A-F | 빠른 참조, 레퍼런스, FAQ |

## 🚀 로컬에서 실행

```bash
git clone https://github.com/coalab/book-claude-code
cd book-claude-code

# 웹 뷰어: web/index.html을 브라우저로 열기
open web/index.html

# PDF: pdf/book.html을 브라우저로 열고 Ctrl+P → PDF 저장
open pdf/book.html
```

## 🤖 이 책이 만들어진 방법

Claude Code가 Claude Code 책을 스스로 작성했습니다.

```
사용된 프롬프트:
"Claude Code 시작하는 사람들을 위한 책을 쓰고 싶습니다."
```

1. 아키텍트 에이전트가 18챕터 목차 설계
2. 5개 작가 에이전트가 병렬로 파트별 집필
3. Python 스크립트로 웹 뷰어 자동 조판

**사람이 한 일**: 프롬프트 작성, 방향 설정
**Claude Code가 한 일**: 나머지 전부
