## 2.1 사전 요구사항: Node.js, npm, Anthropic API 키 발급

Claude Code 설치 전에 필요한 것들을 준비합니다.

### Node.js 설치

Claude Code는 Node.js 기반으로 작동합니다. 버전 18 이상이 필요합니다.

```bash
# 현재 버전 확인
node --version  # v18.0.0 이상이어야 함
npm --version   # v8.0.0 이상이어야 함
```

**Node.js 설치 방법:**

```bash
# macOS - Homebrew 사용
brew install node

# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Windows - 공식 사이트에서 설치
# https://nodejs.org 에서 LTS 버전 다운로드

# 또는 nvm(Node Version Manager) 사용 (권장)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 20
nvm use 20
```

> **💡 팁:** 여러 Node.js 버전을 관리해야 한다면 nvm(macOS/Linux) 또는 nvm-windows를 사용하세요. 버전 충돌 문제를 깔끔하게 해결할 수 있습니다.

### Anthropic API 키 발급

Claude Code 사용을 위해 두 가지 방법 중 하나를 선택합니다:

**방법 1: Anthropic API 키 (종량제)**

```
1. https://console.anthropic.com 접속
2. 계정 생성 또는 로그인
3. "API Keys" 메뉴 → "Create Key"
4. 키 이름 입력 후 생성
5. 키를 안전한 곳에 복사 저장
   (다시 볼 수 없으니 주의!)

형식: sk-ant-api03-xxxxxxxxxxxxxxxxxxxxx
```

**방법 2: Claude.ai Pro 구독 (월 정액)**

```
1. https://claude.ai 에서 Pro 플랜 구독
2. Claude Code 설치 후 claude 명령 실행
3. 브라우저 인증 플로우 자동 진행
4. 별도 API 키 불필요
```

**비용 비교:**

| 방법 | 비용 | 특징 |
|------|------|------|
| API 키 | 사용량 기반 | 팀/기업 사용, 정밀한 비용 제어 |
| Pro 구독 | $20/월 | 개인 사용, 간편한 설정 |

## 2.2 운영체제별 설치 방법

### macOS 설치

```bash
# npm으로 전역 설치
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version

# 만약 권한 오류가 나면:
sudo npm install -g @anthropic-ai/claude-code
# 또는 npm 전역 설치 경로 변경 (권장)
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc
```

### Linux 설치

```bash
# Ubuntu/Debian
npm install -g @anthropic-ai/claude-code

# 권한 문제 해결
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=$HOME/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
```

### Windows WSL2 설치

Windows에서 Claude Code를 사용하려면 WSL2(Windows Subsystem for Linux)가 필요합니다.

```powershell
# PowerShell (관리자 권한)에서 WSL2 설치
wsl --install
wsl --set-default-version 2

# Ubuntu 설치 (Microsoft Store 또는 명령어)
wsl --install -d Ubuntu-22.04
```

```bash
# WSL2 Ubuntu 터미널에서
# Node.js 설치
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Claude Code 설치
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
```

> **💡 팁:** Windows에서 WSL2는 필수입니다. PowerShell이나 CMD에서는 Claude Code가 동작하지 않습니다. WSL2 설치가 번거롭다면 Windows Terminal을 설치하고 Ubuntu 탭을 기본으로 설정하면 편리합니다.

## 2.3 첫 실행과 인증 설정

### API 키로 인증

```bash
# 환경변수로 API 키 설정 (현재 세션)
export ANTHROPIC_API_KEY="sk-ant-api03-your-key-here"

# 영구 설정 (~/.zshrc 또는 ~/.bashrc)
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-your-key-here"' >> ~/.zshrc
source ~/.zshrc

# Claude Code 실행
claude
```

### Claude.ai Pro로 인증

```bash
# 브라우저 인증 플로우 시작
claude

# 자동으로 브라우저가 열리며 로그인 화면 표시
# Claude.ai 계정으로 로그인 후 허용 버튼 클릭
# 터미널로 자동 복귀
```

### 첫 실행 화면

성공적으로 인증되면 다음과 같은 화면이 나타납니다:

```
╭─────────────────────────────────────────────╮
│ ✻ Welcome to Claude Code!                   │
│                                             │
│   /help for help, /exit to quit            │
│                                             │
│ cwd: /Users/username/project               │
╰─────────────────────────────────────────────╯

>
```

### 설치 상태 확인

```bash
# 진단 명령어
claude doctor

# 출력 예시:
# ✓ Node.js version: v20.11.0
# ✓ npm version: 10.2.4
# ✓ Claude Code version: 1.x.x
# ✓ API key: configured
# ✓ Network: connected
```

## 2.4 터미널 환경 최적화 및 Shell 설정

### zsh 최적화 (macOS 기본)

```bash
# ~/.zshrc에 추가

# Claude Code 단축 별칭
alias cc="claude"
alias ccf="claude --dangerously-skip-permissions"  # 자동 승인 (주의!)

# 프로젝트별 빠른 실행
function ccproject() {
  cd "$1" && claude
}

# API 키 관리 (여러 키를 프로젝트별로)
function set-claude-key() {
  export ANTHROPIC_API_KEY=$(cat ~/.claude-keys/$1)
  echo "Claude API key set to: $1"
}
```

### bash 최적화 (Linux)

```bash
# ~/.bashrc에 추가
export ANTHROPIC_API_KEY="your-key-here"

# 히스토리 설정 (claude 명령 기록 보존)
HISTSIZE=10000
HISTFILESIZE=20000
HISTCONTROL=ignoredups:erasedups
```

### Windows Terminal 설정

```json
// settings.json에 Claude Code용 프로필 추가
{
  "profiles": {
    "list": [
      {
        "name": "Claude Code",
        "source": "Windows.Terminal.Wsl",
        "startingDirectory": "//wsl$/Ubuntu/home/username",
        "icon": "🤖",
        "colorScheme": "One Half Dark"
      }
    ]
  }
}
```

### 유용한 환경 설정

```bash
# .claude/settings.json (프로젝트별 설정)
{
  "model": "claude-opus-4-5",
  "permissions": {
    "allow": ["Bash(git *)", "Bash(npm *)", "Bash(pytest *)"],
    "deny": ["Bash(rm -rf *)"]
  }
}
```

> **💡 팁:** API 키를 `.env` 파일에 저장하고 `direnv`를 사용하면 프로젝트 디렉토리에 들어갈 때 자동으로 키가 설정됩니다. 팀 프로젝트에서 서로 다른 API 키를 사용할 때 특히 유용합니다.

## 핵심 요약

1. Claude Code는 **Node.js 18+ 환경**에서 npm으로 설치합니다
2. 인증은 **API 키** 또는 **Claude.ai Pro 구독** 두 가지 방법으로 가능합니다
3. Windows에서는 반드시 **WSL2** 환경이 필요합니다
4. `claude doctor` 명령으로 설치 상태를 확인합니다
5. Shell 설정 파일에 API 키와 별칭을 등록하면 편리합니다
