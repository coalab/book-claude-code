### 실제 버그 사례: 소수점 금액 문제

```typescript
// 버그 있는 코드
async function processPayment(orderId: string) {
  const order = await prisma.order.findUnique({ where: { id: orderId } });

  // 버그: discount가 0.1이면 price * discount = 소수점 발생
  const discountedAmount = order.price * (1 - order.discountRate);

  // PG사 API는 정수(원 단위)만 허용
  await paymentGateway.charge({
    amount: discountedAmount,  // ← 소수점이 들어감!
    orderId: order.id
  });
}
```

```bash
"이 결제 로직의 버그를 찾았어.
 discountedAmount에 소수점이 생길 수 있어.
 예: 15000 * 0.9 = 13500 (OK), 15000 * 0.1 = 1500 (OK)
 하지만 15000 * 0.15 = 2250 (OK)
 근데 15001 * 0.1 = 1500.1 (문제!)

 JavaScript 부동소수점 문제를 고려해서 수정해줘.
 1원 단위로 정확하게 처리해야 해."
```

## 14.2 메모리 누수, N+1 쿼리 등 성능 문제 진단

### N+1 쿼리 문제 탐지

N+1 문제는 성능 저하의 가장 흔한 원인입니다. 루프 안에서 반복적으로 DB 쿼리를 실행하는 패턴입니다.

```bash
# N+1 패턴 탐지 요청
"이 코드에서 N+1 쿼리 문제를 찾아줘:

async function getWorkspaceSummary(workspaceId: string) {
  const tasks = await prisma.task.findMany({
    where: { workspaceId }
  });

  // 각 태스크마다 별도 쿼리 실행 - N+1!
  for (const task of tasks) {
    task.assignee = await prisma.user.findUnique({
      where: { id: task.assigneeId }
    });
    task.comments = await prisma.comment.findMany({
      where: { taskId: task.id }
    });
  }

  return tasks;
}

Prisma의 include로 최적화해줘."
```

수정된 코드:
```typescript
async function getWorkspaceSummary(workspaceId: string) {
  // 단 1번의 쿼리로 모든 데이터 로드
  const tasks = await prisma.task.findMany({
    where: { workspaceId },
    include: {
      assignee: {
        select: { id: true, name: true, avatarUrl: true }
      },
      comments: {
        orderBy: { createdAt: "desc" },
        take: 5  // 최근 5개만
      },
      _count: {
        select: { comments: true }
      }
    }
  });

  return tasks;
}
```

### 메모리 누수 진단

```bash
# Node.js 메모리 누수 분석
"서버가 시간이 지날수록 메모리 사용량이 증가해.
 힙 스냅샷을 찍었을 때 다음 결과가 나왔어:

 [힙 스냅샷 분석 결과 붙여넣기]

 이 패턴에서 메모리 누수 가능성이 있는 곳을 찾고
 EventEmitter, 클로저, 캐시 관련 코드를 검토해줘."
```

일반적인 메모리 누수 패턴:
```typescript
// 문제: 이벤트 리스너 미제거
class DataProcessor extends EventEmitter {
  async process(data: any[]) {
    // 매번 새 리스너를 추가하지만 제거 안 함
    this.on('item', (item) => {
      console.log(item);
    });
    // ... 처리 로직
  }
}

// 해결: 리스너 관리
class DataProcessor extends EventEmitter {
  private itemHandler = (item: any) => { console.log(item); };

  async process(data: any[]) {
    this.on('item', this.itemHandler);
    try {
      // ... 처리 로직
    } finally {
      this.off('item', this.itemHandler);  // 항상 제거
    }
  }
}
```

FROM tasks t

```typescript
// 버그 수정 후 회귀 테스트 (Claude Code 생성)
describe("결제 금액 소수점 회귀 테스트", () => {
  // 버그 재현 케이스들
  const testCases = [
    { price: 15001, discountRate: 0.1, expected: 13501 },
    { price: 10000, discountRate: 0.15, expected: 8500 },
    { price: 33333, discountRate: 0.3, expected: 23333 },
    { price: 1, discountRate: 0.1, expected: 1 },  // 최소 1원
  ];

  testCases.forEach(({ price, discountRate, expected }) => {
    it(`${price}원에 ${discountRate * 100}% 할인 시 ${expected}원`, () => {
      const result = calculateDiscountedAmount(price, discountRate);
      expect(result).toBe(expected);
      expect(Number.isInteger(result)).toBe(true);  // 반드시 정수
    });
  });
});
```
