## 11.1 MCP란 무엇인가: 표준화된 AI 도구 인터페이스

Model Context Protocol(MCP)은 Anthropic이 만든 오픈 표준입니다. AI 모델이 외부 도구, 데이터 소스, 서비스와 표준화된 방식으로 통신하는 프로토콜입니다.

### MCP 이전의 문제

```
MCP 이전:
AI ──→ 도구1 (독자적 인터페이스)
AI ──→ 도구2 (독자적 인터페이스)
AI ──→ 도구3 (독자적 인터페이스)
→ 각 도구마다 다른 통합 방법, 유지보수 어려움

MCP 이후:
AI ──→ MCP 클라이언트 ──→ MCP 서버1 (GitHub)
                      ──→ MCP 서버2 (PostgreSQL)
                      ──→ MCP 서버3 (Slack)
→ 표준 프로토콜로 통일, 재사용 가능
```

### MCP 아키텍처

```
┌─────────────────────────────────────────────┐
│              Claude Code                    │
│         (MCP 클라이언트)                    │
└──────────────────┬──────────────────────────┘
                   │ JSON-RPC over stdio/HTTP
        ┌──────────┴──────────┐
        ▼                     ▼
┌──────────────┐     ┌──────────────┐
│  MCP 서버    │     │  MCP 서버    │
│  (GitHub)    │     │  (Postgres)  │
└──────┬───────┘     └──────┬───────┘
       │                    │
       ▼                    ▼
  [GitHub API]         [데이터베이스]
```

MCP 서버가 제공하는 것:
- **Tools**: Claude가 호출할 수 있는 함수들
- **Resources**: Claude가 읽을 수 있는 데이터
- **Prompts**: 재사용 가능한 프롬프트 템플릿

## 11.2 MCP 서버 설치와 설정 (GitHub, Slack, 데이터베이스 MCP)

### Claude Code에 MCP 서버 추가

```bash
# MCP 서버 추가 명령
claude mcp add <서버이름> <실행명령> [인수...]

# 목록 확인
claude mcp list

# 제거
claude mcp remove <서버이름>
```

### GitHub MCP 설치

```bash
# 설치
claude mcp add github npx @anthropic-ai/mcp-server-github \
  --env GITHUB_TOKEN="ghp_your_token_here"

# 또는 settings.json에 직접 추가
```

```json
// .claude/settings.json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["@anthropic-ai/mcp-server-github"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}
```

GitHub MCP 활용:

```bash
# 이슈 조회
"현재 열려있는 버그 이슈들을 우선순위별로 정리해줘"

# PR 리뷰
"feature/payment 브랜치의 PR을 코드 리뷰해줘"

# 이슈 생성
"TODO 주석들을 GitHub 이슈로 자동 생성해줘"
```

### PostgreSQL MCP 설치

```bash
claude mcp add postgres npx @anthropic-ai/mcp-server-postgres \
  --env DATABASE_URL="postgresql://user:pass@localhost/mydb"
```

PostgreSQL MCP 활용:

```bash
# 스키마 분석
"현재 데이터베이스 스키마를 분석하고
 정규화 문제나 인덱스 개선이 필요한 부분을 찾아줘"

# 쿼리 최적화
"가장 느린 쿼리 10개를 찾고 최적화 방법을 제안해줘"

# 데이터 탐색
"users 테이블에서 지난 달에 가입한 사용자 수를 알려줘"
```

### Slack MCP 설치

```bash
claude mcp add slack npx @anthropic-ai/mcp-server-slack \
  --env SLACK_BOT_TOKEN="xoxb-your-token"
```

Slack MCP 활용:

```bash
# 메시지 분석
"#general 채널의 오늘 메시지에서 주요 이슈를 요약해줘"

# 알림 발송
"배포 완료를 #releases 채널에 알려줘"
```

## 11.3 직접 MCP 서버 만들기: 사내 API 연동 예제

회사 내부 API를 MCP 서버로 만들면 Claude Code가 사내 시스템과 직접 통신할 수 있습니다.

### 기본 MCP 서버 구조 (TypeScript)

```typescript
// my-company-mcp/src/index.ts
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from "@modelcontextprotocol/sdk/types.js";

const API_BASE = process.env.INTERNAL_API_BASE || "https://api.company.internal";
const API_KEY = process.env.INTERNAL_API_KEY;

// MCP 서버 생성
const server = new Server(
  { name: "company-api", version: "1.0.0" },
  { capabilities: { tools: {} } }
);

// 사용 가능한 도구 목록 정의
server.setRequestHandler(ListToolsRequestSchema, async () => {
  return {
    tools: [
      {
        name: "get_employee",
        description: "직원 정보를 조회합니다",
        inputSchema: {
          type: "object",
          properties: {
            employee_id: {
              type: "string",
              description: "직원 ID"
            }
          },
          required: ["employee_id"]
        }
      },
      {
        name: "get_project_status",
        description: "프로젝트 현황을 조회합니다",
        inputSchema: {
          type: "object",
          properties: {
            project_code: {
              type: "string",
              description: "프로젝트 코드"
            }
          },
          required: ["project_code"]
        }
      },
      {
        name: "create_jira_ticket",
        description: "Jira 티켓을 생성합니다",
        inputSchema: {
          type: "object",
          properties: {
            title: { type: "string", description: "티켓 제목" },
            description: { type: "string", description: "상세 설명" },
            priority: {
              type: "string",
              enum: ["low", "medium", "high", "critical"],
              description: "우선순위"
            },
            project_key: { type: "string", description: "Jira 프로젝트 키" }
          },
          required: ["title", "description", "project_key"]
        }
      }
    ]
  };
});

// 도구 실행 핸들러
server.setRequestHandler(CallToolRequestSchema, async (request) => {
  const { name, arguments: args } = request.params;

  switch (name) {
    case "get_employee": {
      const response = await fetch(
        `${API_BASE}/employees/${args.employee_id}`,
        { headers: { "Authorization": `Bearer ${API_KEY}` } }
      );
      const data = await response.json();
      return {
        content: [{ type: "text", text: JSON.stringify(data, null, 2) }]
      };
    }

    case "get_project_status": {
      const response = await fetch(
        `${API_BASE}/projects/${args.project_code}/status`,
        { headers: { "Authorization": `Bearer ${API_KEY}` } }
      );
      const data = await response.json();
      return {
        content: [{ type: "text", text: JSON.stringify(data, null, 2) }]
      };
    }

    case "create_jira_ticket": {
      const response = await fetch(`${API_BASE}/jira/tickets`, {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${API_KEY}`,
          "Content-Type": "application/json"
        },
        body: JSON.stringify(args)
      });
      const data = await response.json();
      return {
        content: [{
          type: "text",
          text: `티켓 생성 완료: ${data.ticket_url}`
        }]
      };
    }

    default:
      throw new Error(`알 수 없는 도구: ${name}`);
  }
});

// 서버 시작
const transport = new StdioServerTransport();
await server.connect(transport);
```

### MCP 서버 등록

```json
// .claude/settings.json
{
  "mcpServers": {
    "company-api": {
      "command": "node",
      "args": ["/path/to/my-company-mcp/dist/index.js"],
      "env": {
        "INTERNAL_API_BASE": "https://api.company.internal",
        "INTERNAL_API_KEY": "${COMPANY_API_KEY}"
      }
    }
  }
}
```

활용 예시:

```bash
"PROJ-2024 프로젝트 현황을 확인하고,
 지연되는 태스크들을 Jira 티켓으로 생성해줘.
 담당자는 직원 ID로 알려줘"
```

## 11.4 MCP 생태계 활용: 공개 MCP 서버 디렉토리 탐색

### 주요 공개 MCP 서버

| MCP 서버 | 기능 |
|---------|------|
| `@anthropic-ai/mcp-server-github` | GitHub 이슈, PR, 코드 관리 |
| `@anthropic-ai/mcp-server-postgres` | PostgreSQL 쿼리 및 스키마 |
| `@anthropic-ai/mcp-server-slack` | Slack 메시지 읽기/보내기 |
| `@anthropic-ai/mcp-server-filesystem` | 파일 시스템 확장 |
| `mcp-server-sqlite` | SQLite 데이터베이스 |
| `mcp-server-brave-search` | Brave 웹 검색 |
| `mcp-server-fetch` | 웹 페이지 가져오기 |

> **💡 팁:** MCP 서버 목록은 계속 증가하고 있습니다. `npm search mcp-server`로 새로운 MCP 서버를 탐색하거나, GitHub에서 `topic:mcp-server`로 검색하세요.

## 핵심 요약

1. **MCP**는 AI와 외부 도구를 연결하는 표준 프로토콜입니다
2. GitHub, PostgreSQL, Slack 등 **공개 MCP 서버**를 즉시 사용할 수 있습니다
3. 사내 API를 **직접 MCP 서버**로 만들어 Claude Code와 연동할 수 있습니다
4. `settings.json`에 MCP 서버를 등록하면 Claude Code가 자동으로 활용합니다
5. MCP 생태계는 빠르게 성장 중이며 다양한 통합이 계속 추가됩니다
