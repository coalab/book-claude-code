## 13.2 단계적 마이그레이션 전략 수립 (빅뱅 vs 점진적)

### 전략 비교

```
빅뱅 마이그레이션:
장점: 한 번에 완료, 기술 부채 완전 해소
단점: 높은 위험성, 장기간 개발 정지, 롤백 어려움

권장 상황: 소규모 앱, 비즈니스 로직 단순, 트래픽 적음

점진적 마이그레이션 (교살자 무화과 패턴):
장점: 낮은 위험성, 지속적 서비스 제공, 단계별 검증
단점: 오래 걸림, 구/신 코드 공존 복잡성

권장 상황: 대규모 앱, 복잡한 비즈니스 로직, 24/7 서비스
```

### 점진적 마이그레이션 계획

```
> 이 레거시 PHP 앱을 Laravel + Vue.js로 마이그레이션하려고 해.
  서비스를 중단하지 않으면서 진행할 수 있는
  6개월 마이그레이션 로드맵을 만들어줘.

  현재 앱의 복잡도와 기능 목록을 고려해서
  어떤 순서로 어떤 모듈을 마이그레이션할지 계획해줘.
```

권장 순서:
```
1단계 (1-2개월): 기반 작업
   → 보안 취약점 긴급 패치 (PHP 5 그대로 유지)
   → Composer, PHPUnit 도입

3단계 (4-6개월): 프론트엔드 현대화
```

## 13.3 테스트 없는 코드에 테스트 추가하기

### Characterization Test 전략

테스트가 없는 레거시 코드를 수정하기 전에, 먼저 **현재 동작을 기록**하는 테스트를 작성합니다:

```
> calculateInvoiceTotal() 함수를 리팩토링하고 싶은데
  현재 테스트가 없어. 이 함수의 현재 동작을 캡처하는
  Characterization Test를 먼저 작성해줘.

  다양한 입력 케이스 (정상, 경계값, 엣지 케이스)를
  모두 포함해줘. 나중에 리팩토링해도 동작이 같은지
  이 테스트로 확인할 수 있어야 해.
```

```python
# 레거시 코드 (분석 대상)
def calculate_invoice_total(items, discount_code, customer_type):
    total = 0
    for item in items:
        price = item['price'] * item['qty']
        if item['category'] == 'TAX_FREE':
            total += price
        else:
            total += price * 1.1  # VAT

    # 할인 적용 (복잡한 레거시 로직)
    if discount_code:
        if discount_code.startswith('SUMMER'):
            discount = 0.1
        elif discount_code.startswith('VIP'):
            discount = 0.2 if customer_type == 'premium' else 0.15
        elif discount_code == 'CLEAR50':
            discount = 0.5
        else:
            discount = 0

        if total > 100000:
            discount += 0.05  # 추가 할인

        total *= (1 - discount)

    return round(total)
```

```python
# Characterization Test (Claude Code가 생성)
import pytest
from invoice import calculate_invoice_total

class TestCalculateInvoiceTotalCharacterization:
    """레거시 함수의 현재 동작을 캡처하는 테스트.
    리팩토링 후에도 이 테스트들이 통과해야 함."""

    def test_no_items_returns_zero(self):
        assert calculate_invoice_total([], None, "regular") == 0

    def test_single_tax_free_item(self):
        items = [{"price": 10000, "qty": 2, "category": "TAX_FREE"}]
        assert calculate_invoice_total(items, None, "regular") == 20000

    def test_single_taxable_item(self):
        items = [{"price": 10000, "qty": 1, "category": "GENERAL"}]
        assert calculate_invoice_total(items, None, "regular") == 11000

    def test_summer_discount(self):
        items = [{"price": 50000, "qty": 1, "category": "GENERAL"}]
        result = calculate_invoice_total(items, "SUMMER2024", "regular")
        assert result == 49500  # 55000 * 0.9

    def test_vip_premium_discount(self):
        items = [{"price": 50000, "qty": 1, "category": "GENERAL"}]
        result = calculate_invoice_total(items, "VIP001", "premium")
        assert result == 44000  # 55000 * 0.8

    def test_large_order_additional_discount(self):
        items = [{"price": 100000, "qty": 1, "category": "GENERAL"}]
        result = calculate_invoice_total(items, "SUMMER2024", "regular")
        # 110000 * (1 - 0.1 - 0.05) = 110000 * 0.85
        assert result == 93500
```

## 13.4 Python 2 → 3, jQuery → React 마이그레이션 실전

### Python 2 → 3 마이그레이션

```
> Python 2.7 코드베이스를 Python 3.11로 마이그레이션해야 해.
  1. 자동 변환 가능한 부분과 수동 검토 필요한 부분을 분류해줘
  2. 2to3 도구를 실행하고 결과를 분석해줘
  3. 자동 변환으로 해결 안 되는 부분들을 직접 수정해줘
```

주요 변경 사항 체크리스트:
```python
# Python 2 → 3 주요 변경사항

# 1. print 문 → print 함수
print "Hello"           # 2.x
print("Hello")          # 3.x

# 2. unicode 처리
u"유니코드"              # 2.x (명시적 unicode)
"유니코드"               # 3.x (기본이 unicode)

# 3. division 연산자
7 / 2 == 3             # 2.x (정수 나눗셈)
7 / 2 == 3.5           # 3.x (실수 나눗셈)
7 // 2 == 3            # 3.x (명시적 정수 나눗셈)

# 4. range vs xrange
range(10)               # 2.x (리스트)
xrange(10)              # 2.x (제너레이터)
range(10)               # 3.x (제너레이터, xrange 제거됨)

# 5. dict 메서드
d.iteritems()           # 2.x
d.items()               # 3.x (뷰 반환)
```

### jQuery → React 마이그레이션

```
> 이 jQuery 스파게티 코드를 React 컴포넌트로 변환해줘.
  기능을 유지하면서 현대적인 패턴으로 작성해줘.
```

```javascript
// 레거시 jQuery 코드
$(document).ready(function() {
  var currentPage = 1;
  var itemsPerPage = 10;

  function loadUsers() {
    $('#loading').show();
    $.ajax({
      url: '/api/users?page=' + currentPage,
      success: function(data) {
        $('#user-list').empty();
        $.each(data.users, function(i, user) {
          $('#user-list').append(
            '<div class="user-item" data-id="' + user.id + '">' +
            '<span class="name">' + user.name + '</span>' +
            '<button class="delete-btn">삭제</button>' +
            '</div>'
          );
        });
        $('#loading').hide();
        updatePagination(data.total);
      }
    });
  }

  $(document).on('click', '.delete-btn', function() {
    var userId = $(this).closest('.user-item').data('id');
    if (confirm('삭제하시겠습니까?')) {
      $.post('/api/users/' + userId + '/delete', function() {
        loadUsers();
      });
    }
  });

  loadUsers();
});
```

```tsx
// Claude Code가 변환한 React 컴포넌트
import React, { useState, useEffect, useCallback } from "react";

interface User {
  id: string;
  name: string;
}

interface UserListResponse {
  users: User[];
  total: number;
}

export function UserList() {
  const [users, setUsers] = useState<User[]>([]);
  const [currentPage, setCurrentPage] = useState(1);
  const [total, setTotal] = useState(0);
  const [isLoading, setIsLoading] = useState(false);
  const itemsPerPage = 10;

  const loadUsers = useCallback(async () => {
    setIsLoading(true);
    try {
      const res = await fetch(`/api/users?page=${currentPage}`);
      const data: UserListResponse = await res.json();
      setUsers(data.users);
      setTotal(data.total);
    } finally {
      setIsLoading(false);
    }
  }, [currentPage]);

  useEffect(() => { loadUsers(); }, [loadUsers]);

  const handleDelete = async (userId: string) => {
    if (!window.confirm("삭제하시겠습니까?")) return;
    await fetch(`/api/users/${userId}`, { method: "DELETE" });
    loadUsers();
  };

  if (isLoading) return <div>로딩 중...</div>;

  return (
    <div>
      {users.map((user) => (
        <div key={user.id} className="user-item">
          <span className="name">{user.name}</span>
          <button onClick={() => handleDelete(user.id)}>삭제</button>
        </div>
      ))}
      <Pagination
        current={currentPage}
        total={total}
        pageSize={itemsPerPage}
        onChange={setCurrentPage}
      />
    </div>
  );
}
```

> **💡 팁:** 레거시 코드를 변환할 때 "이 코드를 현대적으로 바꿔줘"보다 "이 코드가 하는 일을 설명하고, 동일한 기능을 React로 작성해줘"가 더 좋습니다. 이해 → 설계 → 구현 순서가 오역을 줄입니다.
